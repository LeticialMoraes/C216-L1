# C216 — L1 · Sistemas Distribuídos

Repositório de **exercícios, práticas e projetos** da disciplina **C216 — Sistemas Distribuídos** do **Instituto Nacional de Telecomunicações (Inatel)**.

O material cobre conceitos de **sistemas distribuídos**, APIs, containers, testes e integração entre serviços.

---

## Estrutura do repositório

Cada pasta de aula é independente (dependências, `Dockerfile` ou `docker-compose` próprios, quando houver). Entre na pasta correspondente e siga o `README` local, se existir.

| Pasta | Conteúdo (resumo) |
|--------|-------------------|
| [**Aula 1**](Aula%201/) | Exercício introdutório em Python (`sistema_faculdade.py`). Ver [Aula 1/README.md](Aula%201/README.md). |
| **Aula 3** | Aplicação com testes (`main.py`, `pytest`). |
| **Aula 4** | API de alunos (FastAPI), Docker e testes. |
| **Aula 5** | Evolução com PostgreSQL, camadas de serviço e `docker-compose` (API + banco + testes em container). |
| [**Aula 6**](Aula%206/) | Frontend **Flask** (templates Jinja), páginas início / sobre / contato, **Docker Compose** (frontend + backend + Postgres). Detalhes e comandos em [**Aula 6/README.md**](Aula%206/README.md). |
| [**Projeto**](Projeto/) | Projeto da disciplina (frontend React + backend Node). Documentação em [**Projeto/README.md**](Projeto/README.md). |

---

## Como navegar

1. Abra a pasta da aula desejada.
2. Leia o `README.md` dentro dela (quando disponível).
